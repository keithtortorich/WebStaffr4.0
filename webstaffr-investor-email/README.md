# WebStaffr Investor Email Skill

A skill for writing investor update emails and pitches that capture Keith's proven voice and structure.

## What This Does

Generates investor emails for WebStaffr that follow the direct, contractor-focused, numbers-driven narrative that has been proven effective. Captures the service (not software) framing, proof-over-promises approach, and unit economics focus.

## When to Use

- Writing investor updates on milestones
- Composing SAFE pitch emails
- Following up with the cap table
- Communicating progress to new prospects
- Need to maintain consistent voice across all investor communications

## Key Features

- Problem-first structure (contractor pain + math)
- Service narrative reinforcement
- Unit economics prominence
- Proof over promises (live demos, test counts, shipped code)
- No software jargon (no "AI," "platform," "solution")
- Tight, fluff-free prose
- Contractor-centric language

See SKILL.md for detailed guidance on voice, structure, tone, and examples.
